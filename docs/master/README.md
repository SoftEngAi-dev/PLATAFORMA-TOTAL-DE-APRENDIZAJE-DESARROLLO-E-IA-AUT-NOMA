# Documento maestro

Esta carpeta contiene la especificación rectora del producto. El archivo
`CONCEPTO-MAESTRO.md` es una copia íntegra del documento maestro entregado
para iniciar este proyecto.

No modificar, mover ni eliminar el documento maestro. Las implementaciones
deben derivarse de él y las decisiones posteriores deben registrarse en
`docs/decisions`.
