# Conocimiento de cursos v0.1

## Modelo pedagógico

Cada unidad sigue el ciclo:

```text
Contexto → explicación → ejemplo → práctica → comprobación → reflexión → proyecto
```

El contenido no se considera completado por tiempo de lectura. Una lección
debe producir una evidencia observable: respuesta, código, prueba, decisión o
artefacto.

## Cursos iniciales

| Curso | Nivel | Resultado |
| --- | --- | --- |
| Python desde cero | Explorador | Programa pequeño explicable |
| Full Stack | Intermedio | Interfaz conectada a API |
| IA aplicada | Avanzado | Tutor evaluable con supervisión |

## Contrato de una lección

Toda lección debe declarar `objective`, `knowledge`, `exercise` y
`successCriteria`. El tutor puede ampliar ejemplos, pero no debe cambiar los
criterios de éxito sin una nueva versión editorial.

## Medios generativos

Los medios educativos deben explicar una idea, no decorar la pantalla. La
primera animación original está en `apps/web/media/learning-loop.svg` y muestra
el ciclo de aprendizaje. Los vídeos futuros deberán incluir duración,
transcripción, idioma, licencia y una alternativa textual.
