# Mapa de contextos

## Contextos principales

- **Learning:** formación, progreso, evaluación y recomendaciones.
- **Development:** IDE, ejecución, testing, Git y proyectos.
- **AI Platform:** tutor, agentes, memoria, retrieval y orquestación.
- **Platform:** identidad, sincronización, plugins, seguridad y observabilidad.

Los contextos deben comunicarse mediante contratos explícitos. El dominio no
debe depender de proveedores concretos de IA, nube o interfaz.
