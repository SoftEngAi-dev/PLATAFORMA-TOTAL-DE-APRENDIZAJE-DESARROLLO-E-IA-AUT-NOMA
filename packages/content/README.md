# Base de conocimiento curricular

Contenido educativo versionado para cursos, módulos, lecciones, ejercicios y
evaluaciones. Los archivos JSON son portables: la API puede servirlos y un
cliente offline puede cachearlos sin depender de un proveedor de IA.

## Fuentes y criterio

- El documento maestro del proyecto define la progresión de explorador a
  profesional.
- El catálogo público `awesome-gpt-6-astra` se usa únicamente como referencia
  de aprendizaje basado en juegos y experiencias web; no se copia código,
  imágenes ni textos de sus proyectos.
- Los contenidos propios priorizan explicación, práctica, proyecto y evidencia.
